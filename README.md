# 🌐 Portfólio Pessoal - Victor Alexandre

Este é o meu Portfólio pessoal — um espaço simples, direto e com estilo — feito para reunir minhas redes, portfólio e contatos de um jeito prático e moderno.  
O site está disponível em: **[victorperim123.github.io](https://victorperim123.github.io/)**  

---

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de treinar meus conhecimentos em web.  


## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura da página  
- **CSS3** — estilização e responsividade  
- **JavaScript** — alternância de modo claro/escuro  
- **Google Fonts (Inter)** — tipografia moderna e limpa  



## 🚀 Como Executar Localmente

Se quiser abrir o projeto no seu computador:

1. Baixe ou clone este repositório:
 
   git clone https://github.com/victorperim123/Portfolio_victor.git
  
2. Acesse a pasta do projeto:
  
   cd Portfolio_victor

3. Abra o arquivo `index.htm.html` no seu navegador preferido  
   *(ou use a extensão **Live Server** no VS Code para uma experiência melhor).*



## 📂 Estrutura do Projeto

```
Portfolio_victor/
```
